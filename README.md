# Flowers 🌸

Este proyecto es una oda a la naturaleza y a la belleza de las flores. Más que un sitio web convencional, **Flowers** está diseñado como una galería digital o un museo interactivo donde los usuarios pueden admirar la increíble capacidad de la naturaleza para crear combinaciones de colores y formas que desafían la imaginación.

El objetivo principal no es el comercio, sino la apreciación estética y la consulta de información sobre diversas especies florales.

## 🛠️ Tecnologías

Este proyecto está construido utilizando tecnologías web estándar:

-   **HTML5**: Para la estructura semántica del contenido.
-   **CSS3**: Para el diseño visual y la presentación.
-   **JavaScript**: Para la interactividad y lógica de la aplicación.
